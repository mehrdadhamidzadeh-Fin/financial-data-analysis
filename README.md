# Financial Data Analysis & Quantitative Modeling

This repository contains Python Jupyter notebooks for quantitative financial analysis, econometrics, and corporate valuation in the Iranian capital market.

## Projects & Notebooks

### 1. `index-regression-folad-femli.ipynb`
- **Topic:** Econometric and linear regression analysis between the Total Market Index (TEDPIX) and major market drivers (FOLAD & FEMLI).
- **Key Focus:** Beta calculation, correlation matrix, OLS regression modeling, and market sensitivity analysis.

### 2. `femli-financial-analysis-ratios-scenarios.ipynb`
- **Topic:** Comprehensive fundamental and financial statement analysis of FEMLI based on 2-year consolidated financial reports.
- **Key Focus:** 
  - Profitability, liquidity, leverage, and operational efficiency ratios.
  - Scenario analysis and forward-looking financial forecasting.

## Tech Stack & Tools
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Statsmodels, Scikit-learn
